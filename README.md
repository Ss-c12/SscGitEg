项目说明文档：Sushc.html
一、项目概述
项目	内容
项目名称	帅气的小站 / 双生（页面标题）
文件类型	单文件静态网页（HTML + 内嵌 CSS + 内嵌 JavaScript）
文件路径	Sushc.html
技术栈	HTML5 + CSS3 + 原生 JavaScript (ES6+)
运行方式	双击本地打开，或任意浏览器直接访问
用途	个人展示型页面 + 幸运日记录与统计工具

一个极简的个人主页示例，现已升级为包含完整交互逻辑的静态应用。不仅包含基础的图文展示，还新增了“幸运日管理”功能，支持多日期记录、本地持久化保存、过期状态统计以及多维度的数据清理，适合作为入门级前端项目模板。

三、页面结构与功能
text
<div class="box">          卡片容器（居中、圆角、阴影）
├─ <header>  h1 「双生」          页面主标题
├─ <main>                         主内容区（左右分栏 Flex 布局）
│   ├─ <div class="lucky-panel">  左侧：幸运日管理面板
│   │   ├─ <input type="date">    日期选择器
│   │   ├─ <button>               操作按钮组（保存 / 逐个清除 / 全部清除 / 清除过期日）
│   │   ├─ <p id="lucky-result">  状态文字（如：共保存了 X 个幸运日）
│   │   └─ <p id="stats-result">  统计面板（未过期 / 已过期数量，带颜色区分）
│   └─ <div class="img-container">右侧：二次元图片展示
│       ├─ <img>                  作品配图（宽 200px）
│       ├─ <p>                    图片说明
│       └─ <p>                    署名 / 副标题
└─ <footer> 帅帅的小站 / 小美     页脚（双行显示）

核心功能与交互逻辑
幸运日存储：支持连续保存多个日期，自动过滤重复日期。
数据持久化：使用浏览器的 localStorage 进行本地存储，刷新或关闭网页后数据不丢失。
旧数据兼容：代码逻辑自动兼容早期版本只存一条 `myLuckyDay` 的旧数据，并无缝转换为新的数组格式 `myLuckyDays`。
实时数据统计：利用 JavaScript 的 `Date` 对象，将保存的日期与“今天”进行对比，精准统计并渲染出“🟢 未过期”和“🔴 已过期”的日期数量。
多维清理机制：
  - 逐个清除：移除最新添加的一条记录。
  - 全部清除：一键清空所有本地记录。
  - 清除过期日：自动筛选并删除过去的历史日期，保留今天及未来的日期。

视觉与布局要点
响应式适配：使用了 @media (max-width: 600px) 媒体查询，在手机端自动变为“图片在上、面板在下”的垂直布局。
背景与居中：浅蓝渐变背景，body 使用 flex 实现整体垂直水平居中。
卡片样式：白底半透明 + 圆角 + 柔和阴影，突出层级感。
按钮组：使用了 Flex 纵向排列，不同功能的按钮（保存/清除/过期）赋予了不同的主题色（蓝/红/灰）以示区分。

四、使用说明
将 Sushc.html 与图片放在同一目录，建议新建 images/ 文件夹存放图片。
双击 HTML 文件即可在默认浏览器中预览。
操作方式：在左侧日历中选择一个日期，点击“保存”即可加入列表；下方的统计文字会自动更新。

五、已知问题与改进建议
1. 图片使用本地绝对路径（优先级最高）
html
<img src="D:\君の膵臓を食べたい\1.jpg" ...>
该写法只在编写者本人的电脑上有效，换机器、上传到服务器或分享给他人时图片必然失效。
建议改为相对路径：
html
<img src="./images/1.jpg" alt="君の膵臓を食べたい" width="200">

2. 样式与逻辑高度耦合
当前 HTML、CSS、JS 全部混在一个文件里，代码量已达数百行。若后续继续增加功能，维护成本会急剧上升。
建议拆分：
  - style.css （样式表）
  - script.js （逻辑脚本）
  - index.html （仅保留结构）

3. 文件命名
Sushc.html 建议改为 index.html，便于部署到 GitHub Pages、Netlify 等静态托管平台时作为默认首页自动加载。

4. 存储局限性
当前使用 localStorage 存储，数据仅保存在当前浏览器中。如果清除浏览器缓存，数据会丢失。
（可作为后续进阶：接入后端 API 或提供 JSON 导入/导出功能）。

六、可选升级方向
加入暗色模式：使用 @media (prefers-color-scheme: dark) 让页面跟随系统切换深色主题。
动画效果：为统计数字的变化增加过渡动画，为卡片增加淡入效果。
日历 UI 升级：引入第三方日期选择库（如 flatpickr），让日期选择体验更好。
列表展示：目前只能看到统计数字，未来可以在面板下方把具体的幸运日列表以 Tag 标签的形式展示出来。
